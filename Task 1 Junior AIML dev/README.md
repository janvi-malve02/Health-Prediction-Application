# MIRA – Health Prediction System

A health prediction web application built with **Python (Flask)** + **SQLite** + **Anthropic Claude AI API**.

## Features
- **CRUD Operations** – Create, Read, Update, and Delete patient records
- **AI-Powered Predictions** – Claude AI analyses blood test values and generates clinical health remarks
- **Input Validation** – Email format, future-date guard, numeric checks on all blood fields
- **Persistent Storage** – SQLite database (auto-created on first run)
- **Search** – Filter patients by name or email in real time
- **Fallback Mode** – Rule-based prediction if no API key is provided

## Tech Stack
| Layer | Technology |
|-------|-----------|
| Backend | Python 3.10+, Flask 3 |
| Database | SQLite (via Python `sqlite3`) |
| AI/ML API | Anthropic Claude (`claude-sonnet-4-20250514`) |
| Frontend | HTML5, CSS3, Vanilla JavaScript |
| Fonts | Google Fonts – DM Serif Display + DM Sans |

## Setup & Run

### 1. Clone the repository
```bash
git clone <your-repo-url>
cd health_app
```

### 2. Create a virtual environment
```bash
python -m venv venv
source venv/bin/activate      # macOS / Linux
venv\Scripts\activate         # Windows
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Set your API key (optional but recommended)
```bash
# macOS / Linux
export ANTHROPIC_API_KEY="sk-ant-..."

# Windows (Command Prompt)
set ANTHROPIC_API_KEY=sk-ant-...
```
> Without a key the app still runs using built-in rule-based predictions.

### 5. Run the application
```bash
python app.py
```

Open your browser at: **http://127.0.0.1:5000**

## API Endpoints
| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/patients` | List all patients (supports `?q=` search) |
| GET | `/api/patients/<id>` | Get a single patient |
| POST | `/api/patients` | Create patient + run AI prediction |
| PUT | `/api/patients/<id>` | Update patient + re-run prediction |
| DELETE | `/api/patients/<id>` | Delete patient |

## Patient Data Fields
| Field | Type | Validation |
|-------|------|-----------|
| full_name | string | Required |
| dob | date | Required, cannot be future date |
| email | string | Valid email format |
| glucose | float (mg/dL) | Positive numeric |
| haemoglobin | float (g/dL) | Positive numeric |
| cholesterol | float (mg/dL) | Positive numeric |
| remarks | string | Auto-generated by Claude AI |

## How AI Prediction Works
1. User submits valid patient data via the form
2. Backend calls the **Anthropic Claude API** with the blood test values and patient age
3. Claude returns a clinical 2–3 sentence risk assessment
4. The assessment is stored in the `remarks` field and displayed with a colour-coded risk badge (Normal / Review / High Risk)

## Security Notes
- **No API keys are stored in code** – set `ANTHROPIC_API_KEY` as an environment variable
- The `patients.db` file is excluded from git via `.gitignore`
